Robot and System Demonstrations

Task-level demonstrations from RAIDS research programs—spanning embodied data acquisition, aerial manipulation, human–robot collaboration, and digital-twin-enabled manufacturing. All videos play inline; no external links required.

Aerial Dexterous Manipulation

  • Embodied Platform
  • Real-2-Sim-2-Real

2026·Contributors:Benhua GAO, Duidi WU, Chenghao HUANG, Le ZHOU, Xinmiao YU, Xurui BAO

A novel aerial embodied-intelligence platform for dexterous manipulation and interaction in 3D space. It combines aerial mobility with robotic arm manipulation, supports embodied task learning in both simulation and real-world environments, and enables a Real-2-Sim-2-Real workflow for developing transferable aerial manipulation policies.

AR-Guided Intelligent Drilling

  • AR-guided drilling
  • LLM parameterization
  • Human-robot collaboration

2026·Contributors:Wenhang DONG, Haofei MA, Dongpeng LI

An AR-guided intelligent drilling system for industrial robotic machining. Target positions are overlaid onto real workpieces for intuitive hole-location confirmation; large language models translate natural-language instructions into structured machining parameters—enabling more efficient, interactive, and flexible human-robot collaboration in drilling tasks.

Bimanual Package Manipulation

  • Vision-language-action model
  • Robotic manipulation

2026·Contributors:Xurui BAO, Xingchen FU, Le HUANG

A bimanual package manipulation demo developed in collaboration with HKPC using the Flexiv AICO 2 robot. The system opens a sealed box and retrieves its contents by learning from teleoperation demonstrations, with stage-wise decomposition and recovery data supporting robust long-horizon execution.
